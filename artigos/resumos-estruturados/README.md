Com título e referências, os textos passam de 500 palavras (≈ 640 e 590); se o limite incluir as
referências, reduza para três ou quatro.

Estes resumos **não** substituem os resumos dos manuscritos: a IJGSI exige menos de 1.000
caracteres e o Play4Change até 1.800 caracteres. Gerar os .docx: `python gerar.py`.
